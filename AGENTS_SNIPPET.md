## Modo de aprendizaje con OpenCode

Este repositorio usa la Skill local `learning-mentor` para funcionalidades de aprendizaje.
Al iniciar una nueva funcionalidad educativa, cargar `learning-mentor` con la herramienta `skill`.
En PLAN, usar GPT-6.1 Sol / High; en BUILD, GPT-6.1 Sol / Medium (o alternativas disponibles equivalentes).
Investigar patrones existentes antes de implementar; no inventar archivos, rutas ni tablas.
Implementar la mayor parte, dejando exactamente 3 ejercicios de CODIGO y 3 bugs reproducibles (facil, medio y dificil).
No revelar ni corregir las soluciones de esos retos sin solicitud expresa. Proporcionar pistas progresivas.
Usar rama `feature/*` y worktree desde `main`; prohibido merge, push o commits automaticos.
Mantener `main` estable y utilizar `docs/learning/` para el registro publico de retos sin spoilers.
No forzar tests como ejercicios; usar verificaciones minimas para comprobar que el entorno funciona.
El plan del agente concluye cuando deja preparados los retos; los retos del estudiante siguen abiertos.
